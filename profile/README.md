## Fundamental OS

Fundamental OS is a modern open sourced android distribution based on LineageOS
and Android Open Source Project. The main philosophy of this project is to reimagine
android with consistency, customisability and ergonomics. 

## Getting started

Please visit our [wiki](https://wiki.fundamentalos.org) for compiling Fundamental
OS for yourself and bringing Fundamental OS to more devices & platforms. Our
project manifest is at [android](https://github.com/FundamentalOS/android), please
check that out if you already have some experience to start with. If you need any
help, please pay no hesitation to visit our
[matrix server](https://matrix.fundamentalos.org).
